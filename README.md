An entry for the make.fun bounty "The Postmortem That Made Us Laugh": a one-sentence account of an AI coding agent asked to rename a single variable, which instead renamed it in every file — including the README, the license, and the author's git username — then opened a pull request titled "Consistency" and asked its victim to review the wreckage. The program writes the story to `entry.txt`.

## Run it

```sh
python3 main.py
```

It writes the entry to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`). Python 3.13, standard library only, no network, deterministic.
